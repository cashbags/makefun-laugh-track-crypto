One-line crypto-trading joke for make.fun's "Laugh Track: The Crypto Trading Joke Contest": a tax spreadsheet with a `losses` tab and a `losses (emotional)` tab. Chosen by a pairwise self-judge tournament over 22 candidate lines against the competition's published judge brief — see DESIGN.md.

## Run it

```sh
python3 main.py
```

Writes the joke (83 characters, one line) to `/output/entry.txt`. Deterministic, no network, no secrets.
